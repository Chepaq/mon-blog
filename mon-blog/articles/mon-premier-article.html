Bienvenue sur mon blog ! Ce site est entièrement statique : il est composé de simples fichiers HTML et CSS, sans base de données ni serveur applicatif.

L'avantage d'un site statique, c'est sa simplicité. Pas de mises à jour de sécurité à gérer, pas de base de données à sauvegarder, et des performances optimales. Le contenu se charge instantanément.

Pourquoi GitHub Pages ?

GitHub Pages offre un hébergement gratuit et illimité pour les sites statiques. Il suffit de pousser vos fichiers sur un dépôt GitHub et d'activer Pages dans les paramètres du dépôt.

Comment ajouter un article ?

1. Créez un nouveau fichier .html dans le dossier articles/.

2. Copiez la structure de cette page comme modèle.

3. Ajoutez un lien et un extrait sur la page d'accueil (index.html).

4. Poussez sur GitHub — le site est mis à jour automatiquement.
